# Exemples Ancrage

Lecteur principal : une personne qui découvre le projet sur GitHub, sans devoir installer le prototype.

Demande : remplacer les exemples visuels pauvres de deux audits et d'un aperçu de site par des exemples professionnels imaginés, avec un faux établissement, dans les verts du site existant. Les données inventées sont explicitement autorisées pour cette démonstration.

Le parcours illustratif est : dossier Maison Sauge à Annecy, audit de visibilité locale, audit SEO et concurrence, site de restaurant. Les mêmes informations circulent entre les pages. Les indicateurs sont simulés, les photos sont générées et aucun service réel n'est appelé. Les fichiers n'altèrent pas les audits opérationnels du prototype.

Réussite : quatre pages HTML lisibles, deux rapports PDF, photographies chargées, liens utilisables, mise en page sans superposition sur ordinateur et à 390 pixels, captures publiées dans la visite guidée.
