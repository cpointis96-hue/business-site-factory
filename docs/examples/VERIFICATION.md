# Vérification des exemples Maison Sauge

Vérification du 11 octobre 2026, limitée aux pages de présentation. Aucun fournisseur réel appelé.

- Les quatre pages ont été ouvertes à 1280 × 1000 et 390 × 844 pixels : aucune image manquante ni aucun débordement de la page.
- Le parcours dossier → audit local → audit SEO → site → carte → informations pratiques → dossier a été exercé dans le navigateur.
- Le même parcours entre les fichiers HTML a été vérifié sans serveur, avec les photographies et la police embarquées.
- Une revue visuelle indépendante a demandé de rendre les tableaux entièrement lisibles sur mobile. Les captures finales montrent les prix, les actions et les comparaisons dans des lignes empilées ; la revue a confirmé cette correction, sans régression matérielle relevée.
- Les deux PDF A4 ont été exportés, ouverts par un lecteur PDF et inspectés : rapport local de 2 pages, rapport SEO de 3 pages. Le texte, les tableaux et les photographies sont présents.
- Les indices sont cohérents avec les valeurs fictives du dossier : moyenne arrondie de 65,5 pour le rapport local, moyenne de 58 pour le SEO.
- Les photos générées conservent leurs prompts dans les fichiers de provenance adjacents. La copie de Jet est issue des assets existants du projet.

Ces vérifications portent sur la présentation et la navigation. Elles ne valident ni des mesures réelles de référencement ni le moteur d'audit connecté ou un service commercial.
